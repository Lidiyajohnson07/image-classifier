# 🔢 Handwritten Digit Recognizer

Ever wondered how machines read numbers? 
This project teaches a computer to recognize 
handwritten digits 0-9 with 97% accuracy!

## ✨ Highlights
- 🧠 Neural Network model (MLP)
- 🎯 97% accuracy on test data
- 📊 Visual confusion matrix
- 🖼️ Sample prediction gallery

## 🛠️ Built With
- Python | scikit-learn | matplotlib
- seaborn | NumPy | Google Colab

## 🔍 How To Run
1. Open `image_classifier.ipynb` in Google Colab
2. Run all cells
3. See the magic! ✨

## 📈 Model Performance
- Dataset: MNIST Digits (1,797 images)
- Algorithm: Multi-Layer Perceptron
- Accuracy: ~97%
